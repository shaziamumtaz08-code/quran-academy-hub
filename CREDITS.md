# Third-party credits

## Qur'anic script font — Indopak Nastaleeq (Hanafi)

The Arabic script shown in the Mushaf reading card and the Noorani Qaida
workspace is rendered with the **Indopak Nastaleeq (Hanafi, v4.2.2, with waqf
lazmi)** font — the Indo-Pak Qur'anic family used by Quran.com and QuranWBW.

- Source: Quranic Universal Library (QUL) by Tarteel AI — https://qul.tarteel.ai/resources/font/242
- Related text project: https://github.com/marwan/indopak-quran-text
- Provided free of charge by QUL / Tarteel AI for Qur'anic projects.
- The font file is self-hosted on this project's own asset CDN (not hotlinked).

Fallbacks in the same stack: PDMS Saleem Quran, Amiri Quran, Noto Naskh Arabic.
